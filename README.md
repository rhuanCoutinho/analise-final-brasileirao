# ⚽ Brasileirão 2026 - Probabilidades de Rebaixamento & Simulador

Aplicação web completa e interativa para análise preditiva, cálculo probabilístico e simulação de cenários de rebaixamento da Série A de 2026.

---

## 🚀 Como usar a Aplicação


### : Aplicação Web Standalone (Sem Necessidade de Python)
* **Arquivo:** [`index.html`](index.html)
* **Como rodar:** Basta dar duplo clique no arquivo `index.html` ou no atalho `abrir_dashboard_local.bat`.
* **Como compartilhar:**
  * Você pode enviar o arquivo `index.html` diretamente por WhatsApp, Telegram ou e-mail. Ele abre em qualquer navegador no computador ou celular.
  * **Hospedagem Gratuita em 1 minuto:** Pode subir o `index.html` no [GitHub Pages](https://pages.github.com/), [Vercel](https://vercel.com/) ou [Netlify](https://www.netlify.com/) para obter um link público gratuito (ex: `https://meu-usuario.github.io/rebaixamento-br-26`).


## 📋 Recursos da Aplicação Web
1. **Ranking Oficial de Probabilidades:** Tabela completa com probabilidades calculadas via 50.000 iterações Monte Carlo.
2. **Simulador de Resultados:** Altere os vencedores dos jogos chave (Corinthians x Botafogo, Inter x Vitória, Corinthians x Grêmio, etc.) e veja a classificação mudar em tempo real.
3. **Gráficos Visuais:** Gráfico de barras de risco, diagrama de dispersão pontos vs. probabilidade e trajetória das últimas rodadas (R30 a R35).
4. **Matriz de Combinações:** Filtro por equipe mostrando o impacto de cada faixa de pontos na salvação.
5. **Critérios Oficiais da CBF:** Pontos > Vitórias > Saldo de Gols > Gols Pró.
